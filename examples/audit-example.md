# Audit example

## Input

> It's worth noting that the migration completed successfully. The key takeaway is that the new process is robust and streamlined.

## AUDIT output

- Sentence 1 — "It's worth noting that" — remove the attention label and state the result directly.
- Sentence 2 — "The key takeaway is" — cut the meta-commentary.
- Sentence 2 — "robust and streamlined" — check whether both adjectives add specific meaning or are generic praise.

No changes are applied in AUDIT mode.
